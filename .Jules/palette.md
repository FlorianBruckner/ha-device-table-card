## 2026-08-04 - [Dynamic Sort State Accessibility on Table Headers]
**Learning:** In data tables with interactive headers, static hover tooltips or generic screen-reader labels are insufficient. Screen-reader and keyboard users need to know exactly which columns are sorted (and in which direction), plus what action clicking the header will trigger. Binding a `drawCallback` handler to dynamically compute and update header `title` and `aria-label` attributes on every table redraw provides immediate, accessible status updates.
**Action:** Always dynamically update sortable table headers on draw/redraw events with attributes containing both the current state (e.g., "sorted ascending") and the next action ("click to sort descending").
